# CRUD-simples
sistema simples de CRUD com HTML, CSS e JavaScript

## Funcionalidades

- Adicionar tarefas
- Editar tarefas
- Excluir tarefas
- Listar tarefas
- Interface responsiva

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Objetivo

Projeto desenvolvido para praticar manipulação do DOM, funções, arrays, objetos e eventos em JavaScript.
